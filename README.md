**仅提供 `mihomo` 和 `sing-box` 的自用预设模版**

**注意**： > `sing-box` 预设配置核心是 [reF1nd核心](https://github.com/reF1nd/sing-box)，[下载地址](https://github.com/reF1nd/sing-box-releases/releases)

1. 目录结构主要适配于 [AndroidTun](https://github.com/yagh779/AndroidTun)。当然你也可以适当修改使其更加适用于你自己。
2. 填入订阅开箱即用。
3. 自用分流，可能不适用于所有人。可以根据核心wiki自行修改配置：
    1. [mihomo](https://wiki.metacubex.one)
    2. [sing-box](https://sing-boxr.dustinwin.cc.cd)
